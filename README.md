# SARC-Rate — AVMLabs Diagnostic Rate Card & Profile Builder

Automated diagnostics with transparent pricing. Services At Reagent Cost (SARC).

## Overview
- **Transparent Pricing**: B2B processing cost, B2C indicative price, and margin calculation.
- **Dynamic Excel Menu**: Tests and Profiles dynamically fetched and parsed from `CRL TEST MENU FINAL 07.10.2026 (KKK).xlsx`.
- **LPL & CRL Integration**: 78 Local Processing Laboratory (LPL) tests, 147 Central Reference Laboratory (CRL) tests, and 68 comprehensive ready-made profiles.
- **Profile Builder**: Interactive cart with B2B/B2C calculations, margin analysis, and customer-safe printable PDF generation.
- **Export & Print**: Full offline Excel export and letterhead-branded health profile printouts

## Setup & Running Locally
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```
